## Engineering Decisions
- Scoped GitHub access token to the Submitly repository to maintain least-privilege access for agentic tools.
- Ran GitHub MCP server in a Docker container for clean dependency isolation.
- Used Django's built-in `AuthenticationForm`, `login()`, and `logout()` utilities to avoid unnecessary custom auth backends.
- Enforced HTTP POST for the logout endpoint to prevent CSRF logout vulnerabilities.
- Enforced explicit HTTP 403 Forbidden (`PermissionDenied`) on unauthorized cross-role access rather than silent redirection.
- Routed root `/` dynamically: unauthenticated users redirect to login, while authenticated users redirect to their role dashboard.

## Key Learning
- Scoping credentials and running MCP servers in containers provides a secure, reproducible foundation for agentic development.
- Django's built-in authentication components natively support custom user models when `USERNAME_FIELD` is configured.
- Raising `PermissionDenied` in custom decorators provides clean HTTP 403 status code separation from unauthenticated redirects.
- Using `url_has_allowed_host_and_scheme` protects against open redirect vulnerabilities during login redirection.
